progress can be reviewed without a Cloudflare Access login.

- Source of truth: `Halo-Lab/halo-website`, branch `contacts-animated-backdrop`.
- Shows the DarkVeil WebGL backdrop that replaces the old gradient, the
  translucent review cards, the reworked FAQ copy, and the new industry labels.
- Contains just the built page and the assets it references, not the whole site.
- Links to other pages point at the live site, so only this page is a snapshot.
- `robots.txt` and a page-level `noindex` keep it out of search results.
- Delete this folder once the preview is no longer needed.
